# Shortcut on VS code

> **obejctivo**: Usar o VS code de forma eficiente e diminuindo a dependencia do mouse.

* Para duplicar uma linha, use: **(SHIFT + ALT)** + **(SETA PARA CIMA/BAIXO)** -> Nao funciona no ubuntu, ver explicacao no abaixo.

* Para MOVER UMA LINHA, use: **ALT** + **(SETA P/ BAIXO/CIMA)**

* PARA APAGAR LINHA, use: CRTL + SHIFT + K

* PARA ENVELOPAR, use: **(CTRL + SHIFT + P)** + *(digite ou selecione a opcao: **Wrap with Abbreviation** >>> ENTER) + **Tag** desejada.

* Use: **Tag desejada*Nr** + ENTER, ex: **a*5**, vai criar 5 links de uma vez.

* Para editar varias linhas de uma so vez, use: **ALT** + MARCAR COM O CURSOR.

* Para buscar e alterar caracteres ou palavras semelhantes de uma vez: Selecionar + **CTRL + D**.

* Para comentar em qualquer linguagem, use: **CTRL + /**
