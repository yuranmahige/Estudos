				Introducao

Virtualizacao e uma abstracao de recursos, ela tambem necessita de recursos computacionais (memoria, armazenamento, processador, rede..)

Para puder usar uma Maquina Virtual (VM) o CPU do computador precisa aceitar a virtualizacao, a opcao precisa estar activa (na BIOS).

Quanto mais recursos computacionais disponiveis, mais maquinas virtuais podemos executar em silmutaneo.

	
	Requesitos Minimos
	
CPU - com suporte para virtualizacao 2 nucleos
RAM  - 4G de memoria de RAM
Armazenamento - HD com 25G disponivel


	Requisitos Recomendados

CPU - com suporte para virtualizacao 4 nucleos
RAM - 8G de memoria RAM		
Armazenamento - SSD com 40G disponivel


	Tipos de virtualizacao

Virtualizacao Total: utliza um SO como hospedeiro
EX: Oracle VM VirtualBOX, VMware player, Microsoft Hyper-V...
Finalidade: Usuarios finais que precisam de ambientes para testes
Vantagens: Versabilidade, facilidade de uso..
Desvatanges: Baixo desempenho, porque depende da maquina fisica

O curso e focado neste tipo de virtualizacao, a virtualizacao total, onde a maquina virtual depende da nossa maquina fisica, e durante o curso usamos o VirtualBox, existe tambem outro tipo tipo que e a:

Para-VIrtualizacao: Nao depende de um Sistema Operacional hospedeiro
ex: VMware Esxi, Microsoft Hyper-V Server, Citrix XenServer...
Finalidade: Destinado para ambientes de maior porte (servidores corporativos)
Vantagens: Maior desempenho, escabilidade e recursos de alta disponibilidade
Desvantages: Exige maior conhecimento, alto custo operacional.
