		Instalando o VirtualBox

1- Baixar do site oficial e compativel com o seu sistema operacional
2- Seguir os passos para instalacoa.


	Baixando imagens ISO

Para criar uma VM, clicamos em New, mas antes, precisamos baixar a imagem ISO do sistema desejedo.

Para Linux, So acender ao site oficial da distro que queremos e baixar. (nao precisa bootar, so baixar iso)

Para Windows o processo e meio diferente
Por ser um sofware licenciando (pago), a microsoft disponibiliza uma imagem apropiada e com tempo limite de uso de 90 dias.

 link do video passo a passo >>> https://youtu.be/GlzS0FpYefg?si=S5gNukP0NhbscJtX

	Instalando uma VM Linux

Para instalar qualquer SO GNU/Linux, basta clicar em NEW, colocar o nome, escolher a imagem ISO baixada e configurar o dados computacionais, memoria, armazenamento. Importante marcar a opcao Dynamically allocated, para permitir que o espaco aumento de acordo com o uso.

Clicar em start, e instalar ( se nao souber como instalar, so pesquisar, o processo e o mesmo que na maquina fisica)


	Instalando uma VM Windows

Para o caso do windows o processo nao e o mesmo. 
No VB(virtualbox), clicamos em file, importar, e escolhemos o arquivo baixado, configuramos e pronto.

	
	Atencao 

COMO ESTAMOS APRENDENDO E O WINDOWS DA 90 DIAS GRATIS, A MELHOR E RECOMENDADA E DE NAO INICIALIXAR A VM ORGINAL, NAO CLICAR EM START E INSTALAR, ANTES CRIAR UM CLONE, PARA QND O CLONE EXPIRAR, CRIAR OUTRO.


	Criando Clones

Para o uso em apredizando, e recomendavel sempre que usemos clones, para nao afectar a VM orginal, e poder apagar/desfazer em caso de algo der errado, sem comprometer o pai.

Para criar clone, selecionamos a VM orginal com o botao direito e clicamos em clone.

Configuracoes importantes para clones

No tipo de clone, selecionar: Linked clone e no address, Generate New..., assim fica likando ao pai e cria novo endereco.
