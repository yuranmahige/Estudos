# Estrutura de arquivos Linux

O Linux organiza seus arquivos em uma única árvore de diretórios a partir da raiz **`/`**, seguindo o padrão **FHS** (*Filesystem Hierarchy Standard*), mantido pela Linux Foundation (versão 3.0). Diferente do Windows, não há letras de unidade — discos e partições são montados em pastas dentro dessa árvore.

```
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── srv
├── sys
├── tmp
├── usr
└── var
```

| Diretório | Função |
|---|---|
| `/` | Raiz do sistema; todos os arquivos e diretórios estão sob ele |
| `/bin` | Binários essenciais disponíveis para todos os usuários (`ls`, `cp`, `cat`) |
| `/boot` | Arquivos de inicialização: kernel, initrd, boot loader |
| `/dev` | Arquivos-nó de dispositivos (discos, terminais, USB) |
| `/etc` | Arquivos de configuração do sistema (`/etc/passwd`, `/etc/fstab`, `/etc/hosts`) |
| `/home` | Diretórios pessoais de cada usuário (`/home/usuario`) |
| `/lib` | Bibliotecas essenciais para os binários em `/bin` e `/sbin` |
| `/media` | Ponto de montagem para mídia removível (CD, pendrive) |
| `/mnt` | Ponto de montagem temporário de sistemas de arquivos |
| `/opt` | Pacotes de software opcionais de terceiros |
| `/proc` | Sistema de arquivos virtual com informações do kernel e processos |
| `/root` | Diretório home do superusuário `root` |
| `/run` | Dados variáveis de tempo de execução (limpo a cada boot) |
| `/sbin` | Binários essenciais de administração do sistema (`fsck`, `init`) |
| `/srv` | Dados servidos pelo sistema (sites, FTP, repositórios) |
| `/sys` | Informações sobre dispositivos, drivers e recursos do kernel |
| `/tmp` | Arquivos temporários (geralmente limpos a cada reinício) |
| `/usr` | Hierarquia secundária de dados de usuário: programas, bibliotecas, documentação (`/usr/bin`, `/usr/lib`, `/usr/share`) |
| `/usr/local` | Software compilado/instalado manualmente, fora do gerenciador de pacotes |
| `/var` | Dados que variam com o uso: logs (`/var/log`), caches, filas, spool |
| `/var/tmp` | Temporários que persistem entre reinícios |

**Pontos-chave:**
- `/bin` e `/usr/bin`: os primeiros contêm comandos essenciais (necessários em modo single-user); os segundos, comandos não essenciais.
- `/tmp` vs `/var/tmp`: o primeiro é limpo no reboot; o segundo preserva arquivos entre reinícios.
- `/root` ≠ `/`: o primeiro é a pasta do usuário root; o segundo é a raiz do sistema.
