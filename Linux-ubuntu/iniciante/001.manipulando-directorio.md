# Comandos Basicos

Comandos são ordens que passamos ao sistema operacional para executar uma determinada
tarefa.

Cada comando tem uma função específica, devemos saber a função de cada comando e escolher o mais adequado para fazer o que desejamos.

## Manipulacao de Directorio

### ls -> lista os arquivos de um directorio.
 
 **Opcoes:**   
    
     ls -a -> Lista todos arquivos e directorios, inclusive os ocultos.
     ls -A -> Lista todos os arquivos (inclusive os ocultos) de um directório, exceto o directório atual e o de nível anterior.
     ls -B -> Ignora arquivos que terminam com ~ (Backup).
     ls -d -> Lista os nomes dos directórios ao invés do conteúdo.
     ls -h -> Mostra o tamanho dos arquivos em KB, MB, GB.
     ls -l -> lista os arquivos do directório atual em formato longo, exibindo detalhes de cada arquivo/pasta. A saída tem 7 colunas:

**Saida ls -l**

```
-rw-r--r--  1 user user 1.2M Oct 27 10:20 data.txt
```
``` bash
ls -l
total 20
-rw-rw-r-- 1 Yuran Yuran  726 Oct  9 15:24 mensagem1.txt
-rw-rw-r-- 1 Yuran Yuran  632 Oct  9 13:50 mensagem2.txt
-rw-rw-r-- 1 Yuran Yuran  914 Oct  9 13:53 mensagem3.txt
-rw-rw-r-- 1 Yuran Yuran  296 Oct  9 13:59 mensagem4.txt
drwxrwxr-x 2 Yuran Yuran 4096 Oct  9 16:13 TESTE
```

| Coluna | Significado |
|---|---|
| `-rw-r--r--` | **Tipo e permissões** — o 1º caractere indica o tipo (`-` arquivo, `d` directório, `l` link); os 9 seguintes são permissões (r/w/x) para dono, grupo e outros |
| `1` | **Número de links** (hard links) |
| `user` | **Dono** do arquivo |
| `user` | **Grupo** do arquivo |
| `1.2M` | **Tamanho** (em bytes; use `-h` para formato legível como KB/MB) |
| `Oct 27 10:20` | **Data/hora** da última modificação |
| `data.txt` | **Nome** do arquivo |

Combinções úteis:
* `ls -la` — inclui arquivos **ocultos** (que começam com `.`)
* `ls -lh` — tamanho em formato **humano** (KB, MB)
* `ls -lt` — ordena por **data de modificação** (mais recente primeiro)
* `ls -l /caminho` — lista o conteúdo de um **directório específico**

Para ver a documentação completa dos comandos: `man ls`.

### cd -> Navegar em directórios

O comando `cd ou cd ~` -> Serve para voltar ao */home*.\
O comando `cd /` -> Retorna ao directorio raiz\
O comando `cd -` -> Retorna ao directorio anterior acessado\
O comando `cd ..` -> Volta um directorio (usamos `cd ../..` para voltar em dois directorios, *mais que isso continuar a add /..*)

### mkdir -> Criar directório

Um directório é usado para armazenar arquivos de um determinado tipo. O directório pode ser entendido como uma pasta onde você guarda seus papeis (arquivos).

`mkdir [opções] [caminho/directório] [caminho1/directório1]`

**onde**:

*caminho* -> Caminho onde o directório será criado.\
*directório* -> Nome do directório que será criado.

**opções**:

 *-p* -> Caso os directórios dos níveis acima não existam, eles também serão criados.\
 *–verbose* -> Mostra uma mensagem para cada directório criado. As mensagens de erro serão mostradas mesmo que esta opção não seja usada.

Para criar um novo directório, precisamos ter permissão de gravação. Por exemplo, para criar um directório em `/tmp` com o nome de `teste` que será usado para gravar arquivos de teste,precisamos usar o comando `mkdir/tmp/teste`.

Podem ser criados mais de um directório com um único comando `(mkdir /tmp/teste /tmp/teste1 /tmp/teste2)`.

---

### rmdir -> Remover directório/arquivo

Este comando faz exatamente o contrário do mkdir.

O directório a ser removido deve estar vazio e devemos ter permissão de gravação para remove-lo.

`rmdir [caminho/directorio] [caminho1/directorio1]`

**onde**:

*caminho* -> Caminho do directorio que será removido.\
*directorio* -> Nome do directorio que será removido.

É necessário que esteja um nível acima do directorio(s) que será(ão) removido(s). Para remover directorios que contenham arquivos, usamos o comando rm com a opção -r.
