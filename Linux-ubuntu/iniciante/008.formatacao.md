# Formatacao

Formatar é o processo de preparar um dispositivo de armazenamento (como discos rígidos, pendrives ou cartões de memória) para armazenar informações, apagando dados antigos e reorganizando a estrutura de gravação. 

Essa operação é necessária para limpar o espaço, corrigir erros de sistema de arquivos ou mudar o formato para melhor compatibilidade entre sistemas operacionais. 

## Formatação de Pen Drives no Linux

### 1. Identificar o dispositivo

Antes de qualquer coisa, é importante descubrir qual é o "endereço" do pen drive:

```bash
lsblk
```

Veremos algo como:

```
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
sda      8:0    0 465.8G  0 disk 
├─sda1   8:1    0   976M  0 part /boot/efi
├─sda2   8:2    0 460.9G  0 part /
└─sda3   8:3    0   3.9G  0 part [SWAP]
sdb      8:16   1   7.5G  0 disk 
└─sdb1   8:17   1   7.5G  0 part /media/yuran/Flash
```

Aqui o pen drive é **`/dev/sdb`** e a partição é **`/dev/sdb1`**. 
⚠️ **Confirmar sempre** — formatar o dispositivo errado apaga os dados.

---

### 2. Desmontar (unmount)

O pen drive normalmente já vem montado automaticamente. Para formatar, precisa desmontar:

```bash
sudo umount /dev/sdb1
```

Se der erro "device is busy", tente:

```bash
sudo umount /media/user/MYUSB
```

---

### 3. Escolher o sistema de arquivos

| Sistema | Arquivo máx. | Compatível com | Quando usar |
|---------|-------------|----------------|-------------|
| **FAT32** | 4 GB | Linux, Windows, macOS | Máxima compatibilidade, arquivos pequenos, boot |
| **exFAT** | ~16 EB | Linux, Windows, macOS | Arquivos > 4 GB + uso multiplataforma |
| **ext4** | 16 TB | **Somente Linux** | Pen drive usado só em Linux, melhor desempenho |
| **NTFS** | 16 TB | Windows + Linux (com driver) | Compartilhado principalmente com Windows |

**Regra prática:**
- Vai usar em Windows **e** Linux? → **exFAT**
- Vai usar **só** em Linux? → **ext4**
- Precisa de compatibilidade com dispositivos antigos (impressoras, carros, etc.)? → **FAT32**

---

### 4. Formatar com `mkfs`

O comando geral é:

```bash
sudo mkfs -t TIPO /dev/sdb1
```

Mas na prática usa-se o binário específico:

```bash
# FAT32
sudo mkfs.vfat -F 32 -n "MEU_PENDRIVE" /dev/sdb1

# exFAT
sudo mkfs.exfat -n "MEU_PENDRIVE" /dev/sdb1

# ext4
sudo mkfs.ext4 -L "MEU_PENDRIVE" /dev/sdb1
```

> **Diferença sutil:** FAT32 e exFAT usam `-n` para o rótulo; ext4 usa `-L`.

---

### 5. Verificar

```bash
lsblk -f
```

Isso mostra o tipo de sistema de arquivos, o rótulo e o UUID de cada partição.

---

### 6. Montar (se não montar sozinho)

```bash
sudo mkdir /mnt/usb
sudo mount /dev/sdb1 /mnt/usb
```

Para desmontar depois:

```bash
sudo umount /mnt/usb
```

---

### Instalação de pacotes (se necessário)

| Sistema de arquivos | Pacote (Debian/Ubuntu) |
|---|---|
| FAT32 | `dosfstools` (já vem instalado) |
| exFAT | `exfatprogs` |
| ext4 | `e2fsprogs` (já vem instalado) |

```bash
sudo apt install exfatprogs   # se não tiver o mkfs.exfat
```

---

### Resumo do fluxo completo

```
lsblk → identificar /dev/sdX
umount → desmontar
mkfs → formatar
lsblk -f → confirmar
mount → usar
```
