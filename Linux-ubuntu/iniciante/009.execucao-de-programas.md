# Executando um comando/programa no linux

Para executar um comando e necessario que tenha tenhamos permissao de execucao.
Tambem que estamos no caminho(lugar) certo.

Ao executar um comando ele recebera um numero de identificacao,
chamado **PID**(Process Identification), este numero e util para identificar
o processo no sistema e assim ter controle a execucao.

### Path

**Path** e o caminho procura de arquivos/comandos executáveis.
O caminho é armazenado na variável de ambiente *PATH*.

## Tipos de execucao de comandos/programas

1. **Primeiro Plano (foreground)**: O que normalmente usamos, onde, so podemos
executar um comando de cada vez, e so podemos executar outro assim que o mesmo terminar.

2. **Segundo Plano (background)**: Roda os processos em segundo plano, nao precisa
terminar a o processo anterior para executar os proximos. Apos iniciar um comando
em background, e mostrado um numero *PID* e o aviso de comando e novamente mostrado,
permitindo o uso normal do sistema.
    - > Para executar um comando/programa em segundo plano, acrescentamos o caracter **&** apos o final do comando.


**OBS** Mesmo que um usuário execute um programa em segundo plano e saia do sistema, o programa continuará sendo executado até que seja concluído ou finalizado pelo usuário que iniciou a execução (ou pelo usuário root).

***Exemplo***: `mv linux exemplos/linux &`

## Executando programas em sequencias

Podemos executar programas em sequencias com o uso de **;**(ponto e virgula).
*Exemplo*: `tac readme; ls docs/*, echo terceiro`

- **ps**: Mostra os processos que estao sendo executado e tambem mostra qual usuario executou, que horas e outras informacoes.

- **top**: Mostra os programas em execucao. Para sair precione **q**.
