# Curingas - Referência global

Curingas (ou referência global) é um recurso usado para especificar um ou mais arquivos ou diretórios do sistema de uma só vez. 
Este é um recurso que permite que faça-mos a filtragem do que será listado, copiado, apagado, etc.

 São usados 4 tipos de curingas no GNU/Linux:

* `“*”` — Se refere a um nome completo ou ultimo nome de uma extensão, arquivo ou diretório depois da referência.
* `“?”` — Se refere a uma letra na posição que deseja procurar.
* `“[]”` — Se refere a uma faixa de caracteres a ser procurada.
* `“{}”` — Se refere a uma busca de caracteres numa faixa de palavras.

## Exemplos de utilização

### Referência “*”:
 
 > Usamos o **"*"** para buscar todos directorios/arquivos com extensoes/nomes especificos.

 **Exemplos**:

 1. `ls livros/*` -> Devolve a lista de todos arquivos/directorios dentro de `livros/`;
 2. `ls livros/*.pdf` -> Devolve a lista de todos arquivos dentro de `livros/` que terminam em `.pdf`

 ### Referência “?”:

> Usamos o **`?`** para representar caracteres desconhecido em um nome de arquivo ou directório.

 **Exemplos**:

 1. `ls ??vros` -> Vai buscar por arquivos/directorios que terminam com `vros` e comecam com `dois caracteres`, que sao os `??`.
2. `ls livros/?????.pdf` -> Vai buscar arquivos que terminam com `.pdf` e comecam com `cinco caracteres`.


### Referência “{}”:

>  Usamos para especificar múltiplos padrões distintos ou sequências de caracteres em um único comando.

**Exemplos**: 

1. `rm arquivo{1,2,3}.txt` ->  Remove apenas os arquvos: `arquivo1.txt`, `arquivo2.txt` e `arquivo3.txt`.
2. `mkdir teste{1,2,3}` -> Cria três diretórios chamados `teste1`, `teste2` e `teste3`

### Referência “[]”:

> Usamos para especificar um conjunto de caracteres ou um intervalo específico que deve corresponder a um único caractere na posição onde é aplicado.

**Exemplos**: 

1. `rm arquivo[12].txt` -> Remove apenas  os arquivos: `arquivo1.txt` e `arquivo2.txt`.
2. `touch arquivo[1-3].txt` -> Cria os arquivos: `arquivo1.txt`, `arquivo2.txt` e `arquivo3.txt`.

### Principais Combinações e Exemplos (IA)

*   **Padrões Fixos e Variáveis**: O usuário combina `?` e `*` para especificar posições exatas e extensões variáveis.
    ```bash
    ls teste?.txt      # Lista teste1.txt, teste2.txt, etc. (exatamente 1 caractere após 'teste')
    ls teste*.txt      # Lista teste.txt, teste1.txt, teste10.txt, etc.
    ls ?ile*           # Lista qualquer arquivo que contenha 'ile' após um caractere inicial
    ```

*   **Conjuntos e Intervalos**: O usuário usa `[]` para definir caracteres aceitáveis em uma posição específica.
    ```bash
    ls teste[1-3].txt  # Lista apenas teste1.txt, teste2.txt e teste3.txt
    ls teste[1,3].txt  # Lista apenas teste1.txt e teste3.txt
    ls [clst]*         # Lista arquivos começando com 'c', 'l' ou 's'
    ls teste[^2,4].txt # Lista arquivos excluindo aqueles com 2 ou 4 na posição específica
    ```

*   **Expansões de Lista**: O usuário usa `{}` para gerar combinações de strings, útil para criar arquivos ou aplicar extensões múltiplas.
    ```bash
    mkdir aula{1,2,3}  # Cria os diretórios aula1, aula2 e aula3
    ls arquivo{.txt,.doc} # Lista arquivo.txt e arquivo.doc
    ls /etc/*{tab,swd} # Lista arquivos terminando em 'tab' ou 'swd'
    ```

*   **Combinações Complexas**: Múltiplos curingas podem ser encadeados para precisão máxima.
    ```bash
    ls ??st*           # Arquivos com dois caracteres iniciais, seguidos por 'st' e qualquer extensão
    ls [clst][io]?t*   # Padrões muito específicos combinando conjuntos e caracteres únicos
    ```

Esses recursos são essenciais para a eficiência na linha de comando, permitindo operações em massa sem a necessidade de interfaces gráficas.
