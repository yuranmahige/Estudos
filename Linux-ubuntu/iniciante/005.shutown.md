# shutdown

O comando **`shutdown`** desliga ou reinicia o computador de forma **segura**, avisando todos os usuários logados e permitindo que finalizem suas tarefas antes do sistema desligar.

**Sintaxe:**

```
shutdown [opções] [hora] [mensagem]
```

**Opções principais:**

| Opção | Ação |
|---|---|
| `-h` | Desliga o computador (halt/poweroff) |
| `-r` | Reinicia o sistema |
| `-c` | Cancela um shutdown agendado |
| `-P` | Desliga e corta a energia (poweroff) |
| `-H` | Para o sistema sem cortar a energia |
| `-k` | Apenas envia aviso, sem desligar |

**Parâmetro `hora`:**

| Formato | Significado |
|---|---|
| `now` | Imediatamente (equivalente a `+0`) |
| `+SS` | Após SS minutos |
| `HH:MM` | Em um horário específico (formato 24h) |

**Exemplos práticos:**

```bash
# Desligar agora
sudo shutdown -h now

# Reiniciar agora
sudo shutdown -r now

# Desligar em 10 minutos, avisando os usuários
sudo shutdown -h +10 "Sistema será desligado em 10 minutos"

# Agendar desligamento para as 22h30
sudo shutdown -h 22:30

# Cancelar um shutdown agendado
sudo shutdown -c
```

**Como funciona por baixo:**
1. O `shutdown` envia uma mensagem a todos os usuários logados.
2. Cria o arquivo `/etc/nologin` (ou `/run/nologin`) impedindo novos logins.
3. Envia `SIGTERM` aos processos, aguarda encerramento, sincroniza o disco e desmonta os sistemas de arquivos.
4. Muda o nível de execução via `init` (ou `systemd`) para 0 (desligamento), 1 (monousuário) ou 6 (reinicialização).

> **Dica do Guia Foca:** nunca desligue o computador diretamente pelo botão de energia — use sempre `shutdown`, `halt` ou `poweroff` para evitar perda de dados e corrupção do sistema de arquivos.

Em distribuições modernas com `systemd`, os equivalentes são `sudo systemctl poweroff` (desligar) e `sudo systemctl reboot` (reiniciar), mas o `shutdown` continua sendo a melhor opção quando você quer **agendar** e **notificar usuários** em um único comando.
