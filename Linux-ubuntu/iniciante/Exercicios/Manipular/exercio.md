## Criar, Renomeiar, Copiar, ler e Remover

1. Criar sub-directorio **exe00/**;
2. Renomear o arquivo oculto;
3. Copiar o arquivo renomeado, para o sub-directorio **exe00/**;
4. Ler o conteudo do arquivo original;
5. Apagar o arquivo original, ficando so com a copia;
