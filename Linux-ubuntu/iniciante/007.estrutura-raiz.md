## Funcao de cada directorio

- Os directorios com o **icon de seta**, significa que directorios de link, levam a outros directorios.
- Os directorios com o **icon de cadeado ou "X"**, significa que apenas o super usuario tem autorizacao. *Permission dinied*.

### directorios

- **bin, de binarios**: Executaveis dos aplicativos do sistemas. Podemos encontrar: scripts, binarios, executaveis de alguns aplicativos.

- **boot**: Responsavel pela inicializacao do Sistema Operacional;

- **dev, de devices(dispositivo)**: Arquivos do hardware, hdd, sdd...

- **etc**: Arquivos de configuracao dos sofware do usuario;

- **home**: Arquivos do usuario comum;

- **lib**: Bibliotecas, o mesmo em desenvolvimento.

- **lost+found**: Quarda os arquivos que podem ter sido corropidos. Os arquivos podem corroper quando estamos trabalhando e derepente acontece um corte de energia, e dai os arquivos que estavam em processo de escrita corropem, e o linux salva no lost+found.

- **media**: Arquivos de media removiveis, como pen-drives, cartao de memoria, e outros. Porem so aparece se estiverem conectados.

- **mnt**: Serve para o usuario montar as suas particoes.

- **opt**: opcional, alguns brownsers usam esse directorio como o **brave e chorme**.

- **proc, de processos**: directorio de arquivos virtuais, nao existem no disco, sao criados quando o sistema inicializa, e salvos na memoria RAM, logo, sao apagados quando o sistema renicia/desliga.

- **root**: Arquivos do Super Usuario, so acesso restrito.

- **run**: Tempo de execucao: Arquivos virtuais sobre a informacao do sistema, como usuarios logados e outros.

**sbin**: Arquivos de programas que so podem ser executados pelo root.

**snap**: Arquivos da loja de aplicativos snap.

**srv**: Directorio usado em linux server.

**sys**: Um directorio virtual, permite a interacao directa com o kernel do linux.

**temp**: Armazena arquivos temporarios.

**usr**: Executaveis do sistema.

**var**: Arquivos variaveis

**swapfile**: arquivo que serve para enviar dados para o armazenamento, quando a memoria esta cheia.
