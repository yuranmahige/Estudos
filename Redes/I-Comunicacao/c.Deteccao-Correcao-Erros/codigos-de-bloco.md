# CÓDIGOS DE BLOCOS

Nos códigos de blocos, uma mensagem é dividida em blocos, cada um deles com **k bits**, denominados **palavras de dados (datawords)**. Adicionamos **r bits redundantes** a cada bloco para obter o **comprimento n = k + r**. 

> Os blocos resultantes de **n** bits são chamados **palavras de código (codewords**).
