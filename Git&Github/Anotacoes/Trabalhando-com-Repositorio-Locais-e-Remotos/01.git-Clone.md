				Clonando um Repositorio Remoto
				
Para clonar um repositorio, usamos o comando:
git clone url.git
ex: git clone https://github.com/yuranmahige/Git&Github.git

So podemos clonar repoitorios que temos acesso, ou repositorios publicos, se for um repo privado, garantir que o acesso remoto esteja configurado para tal repositorio/conta, verificar
git remote -v

Apos clonar o projecto e termos feito as alteracos, precisamos sincronizar com o nosso remoto, antes do push, usamos o comando:
git pull nome master / git pull


		Protocolos git

o git suporta 4 protoculos: 
	Local > file://url.git - Leitura e Escrita, mesmo computador ou ligados na mesma rede
	
	SSH > git@github.com:url.git - Leitura e Escrita, velocidade, seguranca
	
	Git >  git://ip/url.git - Leitura apenas, sem autentificacao
	
	Http/https > http/https://ip/url.git - Leitua e Escrita, bastante usado por empresas, utilizado pelo protocolo SSH.
