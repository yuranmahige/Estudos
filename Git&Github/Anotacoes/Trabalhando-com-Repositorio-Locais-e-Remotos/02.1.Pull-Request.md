Colaborando em projectos publicos  - pull request

Podemos contribuir em projectos publicos, seja na correcao de bugs ou sugestoes de seguranca, etc
Para fazer contribuir em um projecto publico:


	
	Como podemos enviar essas melhorias? como fazer chegar as melhorias ao's propretario's do projecto no Github?
	
	O pull request  responde essas perguntas
	
1- Acessar o repo do projecto desejado, clicar na opcao Fork (Y), estaremos assim criando uma copia para o nosso perfil do github.

2- Com o Projecto na nosso perfil, clonamos para nossa maquina, git clone url.git (Devemos clonar o projecto que esta no nosso perfil).

3- Tendo o projecto em nossa maquina, aplicamos e subimos para o Github (git add, commit, push)


	E agora? sera que ja foi enviado ao projecto original, a correcao chegou e pronto?
	NAO, precisamos agora fazer um requerimento ao projecto original, pedido que ele avalie a correcao/sugestao feita.
	
4 - Acessamos no nosso perfil o clone do projecto melhorado, e clicamos na opcao:
 pull request > New > create pull request.
 
 Pronto, assim o dono's do repo, vai/vao receber a nossa proposta de melhoria , avaliar e decidir se aceitam ou nao.
 
 
 
 Podes praticar com repo de um amigo/colega/conhecido.
