				Trabalhando com Repositorios Remotos
				
Repositorio remoto e um repo criado em outro computador, chamado de servidor.

Para criar um repo remoto, usamos o comando 
 
 git init --bare nomerepo-remoto.git
 
 O --bare impende que os commits sejam efectuados directamente no servidor (outro computador)
 
 Atencao. ao iniciar um repo remoto. nunca devemos mexer na estrutura/arquivos gerados automaticamente.
 
 
 	Configuracoes
 	
 Para indicar ao git onde esta o nosso repo remoto, precisamos indicar o endereco IP e o caminho.
 
 git remote add nome
 file://endereco.ip.da.maquina/caminho/do/repo-remoto.git
 
 Podemos add mais de um repo remoto, desde que cada tenha um nome diferente.
 
 	
 	##Comanmdos
 	
 git remote > para listar os repo
 git remote -v > para mostrar o nome, url, fetch e push
 git remote rename nomeactaul novonome > para renomear o nome do repo
 
 Para alterar a url, usamos:
 git remote set-url nome url
 
 apos fazer as alteracoes nome/url, devemos verificar com git remote, e comparar o resultado.
 
 e usamos o git push nome-repo master, para subir.
