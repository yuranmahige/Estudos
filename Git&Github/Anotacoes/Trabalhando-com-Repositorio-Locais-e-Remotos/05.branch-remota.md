			Branches remotas

A branch remota e a branch que esta sincronizada com o nosso repo remoto.

Do momento que fazemo push, o a branch vira uma branch remota (origin/master)

No desenvolvimento local o nosso ultimo commit vira (head > master) e quando fazemos push
ganha o atributo (origin/master)

git log -n1 --oneline

b02706e (HEAD -> master, origin/master) Caso real de branch


	##Ligando a branch remota em outros repositorios locais
	
Se clonar-mos um projecto, e verficar-mos, teremos apenas a branch default (master/main).

Consideremos que temos um projecto com duas ou mais branches, a master, updates, testes.

E queremos chega um novo membro na equipa, ao clonar o projecto para a sua maquina local,
e verificar 

git branch -a -v

vai apenas visualizar a branch *master, por ser a principal.
Porem ele faz parte da equipa de testes, e nao pode trabalhar directamente na branch master.

Para ter acesso as outras branches ou a de teste em especifico, deve usar o comando:

git checkout -b nomebranch origin/nomebranch  >> substituir nomebranch pelo nome real da branch.

outro metodo e usando o paramento -t

git branch -t origin/nomebranch


branchs locais criadas apartir de branchs remotas sao chamadas de **tracking branch**
