			Hospedando Repositorios git no github
			
Existem varios servicos de hospedagem, que suportam o git, dentro delas o:
	Github, Bitbucket, Google Code, ...
	
O Github e o principal servico utilizado pelos dev que usam git.

Github e uma ferramenta corporativa, que permite interagir nos repositorios, por meio de algumas funcionalidades como:

Issue Tracker: para criação e gestão de bugs e milestones do projeto;

Pull Requests: para que outros usuários possam enviar seus commits
com alterações no projeto, ou commits com correções de bugs;

Commit Comments: para que os usuários possam comentar e discutir
sobre as modificações no código, de um determinado commit.

Além disso, no GitHub é possível criar organizações, e dentro delas criar
equipes.

No Github podemos pesquisar por repositorios publicos, assuntos, ferramentas, perfis de usuarios, etc...
