			Manipulando Branchs
	
Vamos comecar por trocar de uma branch para outra.

		Trocando de branch

Para mundar de branch, usamos o comando:
	
	git checkout nomedabranch

E verficamos, git branch, veremos que o * foi para nossa outra branch.

De Lembrar que o comando git checkout, usamos para desfazer mudancas nao rastreadas.
 (Registrado nas anotacoes anteriores).

Podemos criar e ja trocar e branch com um so comando. o:

	git checkout -b nomedabranch
	
e se verificamos, veremos que a branch foi criada e o * esta apontado para nossa nova branch.

		Deletando uma branch                                                                    

Para remover uma branch, primiros precisamos garantir que nao estamos nela,
que o * na aponte para branch que queremos apagar.

tendo confirmado, usamos o comando:

	git branch -d nomedabranch
	
Porem, nao e possivel apagar uma branch ja tenham sido feitos commits dentro dela.
Nesse caso, precisamos mesclar as branch primeiro. Caso os commits nao sejam importantes,
usamos a opcao -D, em vez de -d:

	git branch -D nomedabranch.
	
		Mesclando branch
		
Ao fazer uma mesclagem, a branch sendo mesclada, vai mesclar com aqui aponta o *.

Ao fazer alteracoes em branchs diferentes, podemos notar que as alteracoes seram diferente para cada uma,
como se fossem projectos / versoes diferentes, para que se interlacem, precisamos mescla-las.

Primeiro verificamos as branchs nao mescladas, com o comando:

	git branch --no-merged
	
Apos, podemos meclar com o comando
	
	git merge nomedabranch -m "escreva a mensagem para commit"
	
Se executarmos o git branch --no-merged, veremos que nao teremos mais mada, porque foi mesclado.

Se formos verificar os log, com parametro --parents, veremos que o ultimo commit de master e a nova branch, foram mesclados, criando um novo commit.


		cuidados ao mesclar

Se nao tivessemos feito nenhum commit no master, o merge entre elas faria o master apontar para a nova branch.
Essa mesclagem e chamada de fast-forword, e para evitar que isso acontecesse, usariamos o comando:

	git merge --no-off nomedabranch -m "a mensagem"
	
	
		Mesclagem com varias branchs
		
Outra forma de mesclar branchs, e usando o parametro o rebase.

	git rebase nomebranch
	
ao usar o rebase, ele nao cria commits de merge, e nao deixa o historico com commits sem necessidade.

ao executar dessa maneira, o master vai msclar e depois replicar o ultimo commit de master.
Dixando assim o commit replicado inutil, e esempre bom manter limpo e organizado o istorico de commits.

Para evitar ou melhor, fazer da forma certa, devemos:

1-mudar de branch, ir para novabranch
git checkout novabranch

2- fazer o rebase, estando la
git rebase master


com isso fariamos o ultimo commit do design o commit da master, mantendo o historico limpo.
