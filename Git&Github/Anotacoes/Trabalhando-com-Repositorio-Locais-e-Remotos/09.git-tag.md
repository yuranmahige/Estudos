				Tags marcadores versoes

Usamos o git tag, para marcar versoes / pontos / marcos... no nosso codigo, servem como marcadores fixos.


Os nomes permitidos para tags e branches têm algumas restrições:
não podem conter: ~, ^, :, além de sequências de caracteres como .. e @{.

Para mais info, acesse: http://git-scm.com/docs/git-check-ref-format.html

 ##Exemplo de uso
 
Quando terminamos o nosso projecto (projecto "nunca" termina, sendo assim),  ou melhor quando chega-mos em um ponto estavel e aceitavel do nosso projecto, podemos marcar esse ponto, usando o git tag que ficara no nosso historico. exemplo terminamos a v1.0 estavel.

e podemos marcar extamente esse marco no nosso historico.

Para tal usamos o comando:

git tag titulodatag ID - do commit

ex: git tag v1.0 97f357d

E para deletar uma tag, usamos o parametro -d

git tag -d v1.0

essa forma e a mais simples de usar tags, podemos passar mais informacoes nas tags.

	
	##tag com informacao
	
Podemos marcar uma tag com mais informacoes, com mais detalhes, como: 
O autor, o data e uma mensagem.
Para tal, usamos o comando:

git tag -a titulodatag -m "mensagem"

ex: git tag -a v1.0 -m "Versao estavel"

e Para exibir usamos:

git show -s titulodatag

O comando git show não serve apenas para exibir informações de tags.
É possível utilizá-lo para inspecionar commits e outros detalhes internos do Git.


		##Compartilhando Tags

As tags criadas localmente, ficam apenas no nosso repo local, ao fazer git push, elas nao sao incluidas,
Para inclui-las, devemos fazer um push dedicado a elas, usamos o comando:

git push origin titutodatag

esse comando serve para tags em especifico, para todas tags locais, usamos:

git push origin --tags
