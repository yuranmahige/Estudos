		Organizando o trabalho com branches
		
Branch e uma linha independente de desenvolvimento em que 
podemos commitar novas versoes do codigo sem afectar outras branchs.

Para listar branches, usamos o comando:
	git branch

teremos como resposta:

	* master

isso porque o master, e o padrao do git.
O * indica a branch actual, em que estamos trabalhando.

Para mostrar o ultimo commit de todas branchs, usamos o comando:

	git branch -v
	

	E importante saber que um commit armazena, o commit pai,
	que e o efectuado anteriormente. Um commit pode ter varios pais.
	Para verificar os pais de commit, usamos o comando:
	
	```bash
		git log --parents
	```
E  para verificar o commit pelo qual o master esta apontando, usamos a opcao 
	--decorate, ficando: git log --decorate
	
	
		Criando uma branch
	
Para cria uma branch, usamos o comando:
	git branch nomedabranch

simples quanto a isso, e lembrando da regra deve ser um nome que
condiga com a funcao ou objectivoda branch.

Para verificar se realmente foi criada, usamos: 
	git branch.
	
veremos duas branch, e o * estara apontando para nossa master ainda.
