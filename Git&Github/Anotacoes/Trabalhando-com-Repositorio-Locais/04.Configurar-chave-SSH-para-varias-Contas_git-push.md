
Para configurar uma segunda conta GitHub no mesmo computador sem conflitos, você precisa usar **chaves SSH diferentes** e configurar o arquivo `~/.ssh/config` para dizer ao Git qual chave usar para qual conta.

Aqui está o passo a passo seguro:

### 1. Gerar um novo par de chaves SSH
Não apague a chave atual (`id_ed25519`). Vamos criar uma nova com um nome diferente, por exemplo, `id_ed25519_outra`:

```bash
ssh-keygen -t ed25519 -C "seu_email_outra_conta@gmail.com" -f ~/.ssh/id_ed25519_outra
```
*   Quando perguntar onde salvar, pressione **Enter** para aceitar o padrão (`~/.ssh/id_ed25519_outra`).
*   Defina uma frase-senha (passphrase) ou deixe em branco.

### 2. Adicionar a nova chave pública ao GitHub
1.  Mostre a chave pública:
    ```bash
    cat ~/.ssh/id_ed25519_outra.pub
    ```
2.  Copie o conteúdo (começa com `ssh-ed25519` e termina com o email).
3.  Vá para o GitHub > **Settings** > **SSH and GPG keys** > **New SSH key**.
4.  Cole a chave e salve.

### 3. Configurar o arquivo `~/.ssh/config`
Este é o passo mais importante para evitar conflitos. Vamos dizer ao SSH qual chave usar para cada domínio.

Edite o arquivo de configuração:
```bash
nano ~/.ssh/config
```

Adicione ou altere o conteúdo para ficar assim:

```text
# Conta Principal (Atual)
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes

# Conta Secundária (Nova)
Host github-outra
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_outra
  IdentitiesOnly yes
```

*   **Nota:** Na conta secundária, usamos `Host github-outra`. Isso cria um "alias". Quando você usar `github-outra` no Git, ele saberá usar a chave nova, mesmo que o site real seja o `github.com`.

Salve o arquivo (no nano: `Ctrl+O`, `Enter`, depois `Ctrl+X` para sair).

### 4. Testar as conexões
Verifique se o SSH está reconhecendo as duas contas:

```bash
# Teste da conta principal
ssh -T git@github.com

# Teste da conta secundária (usando o alias criado)
ssh -T git@github-outra
```

Se der sucesso, você verá mensagens como:
*   `Hi yuran! ...` (para a principal)
*   `Hi [nome_da_outra_conta]! ...` (para a secundária)

### 5. Como usar no seu projeto local
Agora, quando for configurar o repositório para usar a **outra conta**, você deve usar o alias `github-outra` no lugar de `github.com` no URL:

```bash
# Dentro da pasta do seu projeto
git remote add origin git@github-outra:yuranmahige/Estudos.git
```
*(Substitua `yuranmahige` pelo usuário da outra conta se necessário)*


E verifique novamente, git remote -v

Para add conta usamos: git remote **add** origin git@github:nome/repo.git

Para mudar / usar outra conta usamos: git remote **set-url** origin git@github
