# Introducao

SSH, Shell Seguro, é uma forma de comunicacao segura de rede entre clientes e servidores SSH.

Usado para acessos remotos, partilhar ficheiros na Internet e outros de forma seguranca. Todas as comunicacoes sao criptografadas e portegida com seguranca moderna.

Embora SSH signifique Shell Seguro, ele nao e um *shell* verdadeiro o sentido do shell vem do Unix e do shell C.
SSH serve para criar um canal para executar um shell em um computador remoto, com criptografia ponta a ponta entre dois sistemas.

> Porem bem sabemos que nada é 100% seguro.

# Protocolo SSH

O protocolo SSH abrange autenticação, criptografia e integridade dos dados transmitidos por uma rede.

* **Autenticação**: Verifica a prova digital da identidade do cliente e do servidor. 
Verifica e confirma que cliente é cliente e Servidor é Servidor.

* **Criptografia**: Criptografa os dados durante toda a comunicacao.

* **Integridade**: Garante que os dados cheguem de forma segura e sem alteracao durante o processo.
